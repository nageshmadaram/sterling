# ORION Parity & Provenance Contract

> **ORION observable parity is a reconstruction-validation problem. Sterling decision-model quality is a trading-model validation problem. They are separate gates and must never be optimized into one metric.**

## 1. Provenance Hygiene

Sterling does not claim to have recovered proprietary ORION formulas, weights, or private predicates.

All decision outputs generated by the Opening Volume engine carry explicit provenance metadata:

```json
{
  "model_id": "sterling_opening_decision_v1",
  "parity_target": "ORION",
  "parity_status": "partial_observable_only",
  "sterling_execution_eligible": true
}
```

Proprietary ORION decision parity remains explicitly marked `UNKNOWN / not measurable`.

---

## 2. Two-Layer Validation Contract

### Layer 1: Observable Parity Dataset (v1 Acceptance Targets)

The observable parity dataset compares facts that can be genuinely observed from ORION across at least **20 independent market sessions** (preferably **30+ sessions**):

| Metric | Paper-validation gate |
|---|---:|
| Direction agreement | **≥ 98%** |
| Leader/event detection precision | **≥ 95%** |
| Leader/event detection recall | **≥ 95%** |
| Event F1 | **≥ 95%** |
| Visible signal timestamp within ±1 minute | **≥ 95%** |
| Visible signal timestamp within ±2 minutes | **≥ 99%** |
| ORB direction/event agreement | **≥ 98%** |
| Tier/visible-label agreement where comparable | **≥ 90%** |
| Sessions with unexplained Sterling-only signals | **< 3%** |
| Sessions with unexplained ORION-only signals | **< 3%** |
| Observable-field coverage | **≥ 95%** |

### Layer 2: Sterling-Owned Decision Model

The **Sterling-owned decision model** (`sterling_opening_decision_v1`) is evaluated on its own merits (`score >= 55`, `conviction >= 5/7`, Box X/Y and COMBO rules) and must NOT be tuned merely to imitate ORION.

Before paper execution, the Sterling decision model requires:
1. Sufficient sample size across 20+ sessions.
2. Out-of-sample chronological holdout performance.
3. Stable performance under nearby threshold perturbations (score `50/55/60/65` and conviction `4/5/6`).
4. Absence of material degradation across market regimes.
